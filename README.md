## 🇧🇷 Português

### 📌 Descrição
Projeto desenvolvido em **Java** com foco em **Programação Orientada a Objetos (POO)**, simulando o funcionamento básico de um sistema de loja com controle de estoque, carrinho de compras e finalização de vendas.

### ⚙️ Funcionalidades
- Cadastro de produtos com:
  - ID
  - Nome
  - Descrição
  - Preço
  - Estoque
- Controle de estoque (baixa e reposição)
- Carrinho de compras com múltiplos itens
- Atualização automática de quantidades
- Cálculo de subtotal por item
- Cálculo do valor total da compra
- Finalização da venda com verificação de estoque

### 🧱 Estrutura do Projeto
- `Produto` — Representa os produtos da loja
- `ItemCarrinho` — Produto + quantidade
- `Carrinho` — Gerencia os itens do carrinho
- `Venda` — Valida estoque e finaliza a venda
- `Main` — Simulação do fluxo do sistema

### 🛠️ Tecnologias Utilizadas
- Java
- IntelliJ IDEA
- Git & GitHub

### 🎯 Objetivo
Projeto criado para **aprendizado**, prática de POO e composição de **portfólio acadêmico e profissional**.

## 🇺🇸 English

### 📌 Description
Project developed in **Java** focusing on **Object-Oriented Programming (OOP)**, simulating a basic store system with inventory control, shopping cart, and sales checkout.

### ⚙️ Features
- Product registration with:
  - ID
  - Name
  - Description
  - Price
  - Stock
- Inventory control (decrease and restock)
- Shopping cart with multiple items
- Automatic quantity update
- Item subtotal calculation
- Total purchase calculation
- Sale checkout with stock validation

### 🧱 Project Structure
- `Produto` — Represents store products
- `ItemCarrinho` — Product + quantity
- `Carrinho` — Manages cart items
- `Venda` — Validates stock and completes the sale
- `Main` — System flow simulation

### 🛠️ Technologies
- Java
- IntelliJ IDEA
- Git & GitHub

### 🎯 Purpose
Project created for **learning purposes**, OOP practice, and **academic/professional portfolio**.
